# Work-item contract

A material work item is executable only when it identifies:

- type: directive, recurring service, incident, or decision;
- target repositories or services;
- user outcome and decision context;
- in-scope and out-of-scope work;
- acceptance criteria;
- required evidence;
- maximum permitted operation class;
- timing or condition;
- failure and rollback behavior.

ChatGPT should infer and structure routine details from current repository state rather than delegating bookkeeping to the user. Ambiguity that does not affect safety or the main outcome should be resolved with a documented, conservative assumption.

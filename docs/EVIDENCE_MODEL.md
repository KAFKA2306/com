# Evidence model

A complete result may require multiple evidence layers:

1. **Contract evidence** — the directive or service defines the intended outcome.
2. **Implementation evidence** — the diff, commit, pull request, and tests show what changed.
3. **Integration evidence** — merge, release, deployment, or artifact publication completed for the intended revision.
4. **Runtime evidence** — the resulting behavior was directly observed.
5. **Domain evidence** — financial values, scientific claims, product data, or other substantive content was reconciled against primary sources.

Do not substitute one layer for another. For example, a merge is not runtime evidence, and a rendered page is not domain-data validation.

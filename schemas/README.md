# Schemas

- `repository.schema.json` — repository roles, visibility classification, capabilities, and canonical domains
- `service.schema.json` — recurring-service contracts
- `schedule.schema.json` — schedule references and activation state
- `evidence-gate.schema.json` — exact revision, required checks, acceptance criteria, and evidence for PASS / FAIL / UNVERIFIED merge gates

The standard-library validators enforce the portfolio invariants that matter for current registries and evidence gates. Schema files document the complete machine-readable contract.

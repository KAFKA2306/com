# ChatGPT-first design

ChatGPT-first means that the user's ordinary natural-language conversation is the primary way work is initiated, refined, reviewed, and interpreted. It does not mean that chat memory is authoritative.

Durable state is written to GitHub:

- Issues retain intent, permissions, acceptance criteria, dependencies, and status.
- Pull requests and commits retain implementation.
- Actions and deployments retain execution references.
- `com` policies and registries retain portfolio boundaries.

This arrangement preserves the low-friction interaction the user actually uses while making the resulting work auditable and recoverable outside a conversation.

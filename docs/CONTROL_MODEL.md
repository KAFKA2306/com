# Control model

## Interaction plane

ChatGPT receives the user's natural-language intent, gathers current evidence, coordinates repository work, and reports decisions.

## Durable control plane

GitHub Issues in `com` retain directives, recurring-service contracts, incidents, decisions, dependencies, and closure evidence. Policies and registries are version controlled.

## Implementation plane

Target repositories own code, data, tests, assets, releases, and deployment configuration.

## Execution plane

GitHub Actions, local runtimes, and scheduled tasks execute bounded operations. Their queue and runtime state are not canonical.

## Evidence return

Every material execution returns exact references and observed outcomes to the governing work item. This closes the loop between conversational intent and auditable repository state.

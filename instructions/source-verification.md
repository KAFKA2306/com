# Source verification procedure

For public facts used in portfolio decisions:

1. search current primary sources before relying on model memory;
2. verify the official name, date, number, version, and specification at the source;
3. prefer filings, official documentation, standards, release notes, and first-party datasets;
4. remove claims that cannot be confirmed;
5. distinguish event date from publication date;
6. recheck the final output for unsupported or stale statements;
7. record the exact URL and observation date in the governing work item or target artifact.

For repository facts, use connected GitHub state and exact file, issue, pull request, commit, workflow, release, or deployment references. Do not use an old chat summary as current repository evidence.
